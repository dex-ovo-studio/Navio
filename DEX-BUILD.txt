Navio — Windows x64 构建

环境
Windows x64、Node.js 24+、package.json 指定版本的 pnpm。
客户端源码基于 Clash Party 2.0.4；内核固定为 Mihomo v1.19.32。

1. 准备固定运行资源
下载并解压 Clash Party 2.0.4 Windows x64 portable：
https://github.com/mihomo-party-org/clash-party/releases/tag/v2.0.4
https://github.com/mihomo-party-org/clash-party/releases/download/v2.0.4/clash-party-windows-2.0.4-x64-portable.7z

归档 SHA-256：182063a60b9a06535d176742d627f8b8c95a99aae85fc8752c880efee7da5157
resources/app.asar SHA-256：801ad4a2dfd770ae4007879d8cf2d5e4f19dbfc92b02703b30b908f846e75abe
内核与原生模块校验值见 PINNED-RESOURCES.json。

将参考包中的 resources/files、resources/sidecar 分别复制为项目的 extra/files、extra/sidecar。保留资源内容和目录结构；不要用其他版本的资源替换。

2. 安装依赖
在项目目录执行：
    pnpm install --ignore-scripts --frozen-lockfile

3. 编译
    node scripts/build-native.mjs

输出位于 out/main、out/preload、out/renderer。该入口需要 Node.js 24+；配置与分进程构建选项见 NATIVE-BUILD.txt。

4. 生成安装包与便携包
    node scripts/release-windows.cjs "<参考包目录>" "<新产物目录>" "<新暂存目录>"

产物目录、暂存目录必须不存在，并与源码、参考包及彼此分开。命令执行完整编译和打包，生成 Windows x64 setup.exe、portable.zip、SHA256SUMS.txt 和 RELEASE-MANIFEST.json；不会安装或发布程序。

首次打包会下载固定版本的 NSIS 与归档工具。服务宿主由 Windows 自带的 .NET Framework 编译器编译。第三方运行时、内核和原生模块使用已核验的固定二进制。

如只需生成解压后的程序目录，可在完成编译后运行：
    node scripts/package-pinned.cjs "<参考包目录>" "<新程序目录>" "<新暂存目录>"

仅当 out 来自相同源码的完整编译时，release-windows.cjs 可使用 --skip-build。

5. 检查
    pnpm run format:check
    pnpm run lint:check
    pnpm run typecheck
    node --test scripts/release-windows.test.cjs scripts/release-windows-safety.test.cjs

运行测试使用独立配置目录。实际安装、升级、系统代理和 TUN 需在 Windows 测试环境中验证。

发布材料
保留 LICENSE、DEX-THIRD-PARTY-NOTICES.txt、third-party/ 以及与二进制对应的源码、锁文件和构建脚本。内核与第三方源码获取方式见 third-party/README.txt。
分发包不附带历史 GeoIP / ASN / GeoSite / BundleMRS 数据；用户可在软件内按需下载。
